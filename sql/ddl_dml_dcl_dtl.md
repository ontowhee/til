# DDL, DML, DCL, DTL
Reference: https://stackoverflow.com/a/44796508

- DDL - Data Definition Language - commands used to define tables (CREATE, DROP, ALTER, TRUNCATE, COMMENT, RENAME)
- DML - Data Manipulation Language - commands used to change data (SELECT, INSERT, UPDATE, UPSERT, DELETE, MERGE, CALL, EXPLAIN PLAN, LOCK TABLE)
- DCL - Data Control Language - commands concerned with rights and permissions (GRANT, REVOKE)
- TCL - Transaction Control Language - commands managing db transactions - (COMMIT, ROLLBACK, SAVEPOINT, SET TRANSACTION)
